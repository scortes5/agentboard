Skills and Agents

Claude Code subagents: specialized assistants with their own instructions and tools. Claude uses them when the description matches the task, or when you ask ("use the reviewer agent").

Connect your subscriptions to AgentBoard and they can talk to each other: an agent can see the others, hand them a task, read their answer or open a new one. Example: ask Claude "ask Codex what it thinks of this change". Everything goes through a local channel on this computer; it only ever writes to agents, never to plain terminals.

Skills bundled with AgentBoard so each subscription spends fewer tokens and less context. They are installed as SKILL.md in each CLI's skills folder; you can edit or delete them at any time.

What else AgentBoard does to save tokens

  • A new session per task: each to-do starts with a clean context instead of dragging along long conversations.
  • Light mode (! in the task): uses that subscription's cheaper model (--model haiku, low reasoning in Codex, Flash in Gemini). Edit it in Settings → Agents.
  • Split with AI uses claude -p --model haiku --tools "": one short call, no tools (minimal system prompt), no terminal and no repository access.
  • Spread across subscriptions: "auto" sends each task to the least busy subscription, so you don't exhaust a single limit.
  • Compact handoffs: "Send to…" and send_to_agent send a summary, not the whole history.
