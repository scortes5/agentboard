# AgentBoard Wiki

**AgentBoard** is a free, open-source desktop app (macOS and Windows) that puts your coding agents — **Claude Code, Codex, Gemini CLI** and more — side by side on an infinite board of real terminals. Hand them tasks, spread work across your subscriptions, and automate whole workflows. No API keys, no servers, no telemetry.

## Why AgentBoard?

- **Many agents at once**, each in its own real terminal (PTY), project and git branch.
- **Your own subscriptions**: it runs the CLIs you already have signed in. Several Claude accounts are spread automatically, and if one hits its usage limit the work moves to another.
- **Worktree per task**, so parallel agents never step on each other in the same repo. Review, merge or discard each one.
- **Automations** drawn as diagrams: trigger → agent → command → decision → notify. The AI can design and explain them for you.
- **Runs in the background**: close the window and the agents keep working; reopen and each card resumes its own session.
