# Glossary

| Term | Meaning |
|---|---|
| **Agent** | An AI assistant that works on your code (Claude Code, Codex, Gemini CLI…). Each one is a card. |
| **CLI** | A program used from the terminal. |
| **PTY** | A pseudo-terminal: what makes each card a real terminal. |
| **Subscription** | Your plan with an AI provider; agents run on it. |
| **Project** | A folder with code; a tab at the top. |
| **Group** | A frame on the board gathering several agents. |
| **Task** | A to-do an agent carries out in a fresh session. |
| **Automation** | A diagram of steps that runs by itself. |
| **Worktree** | An extra working copy of a git repo on its own branch. |
| **MCP** | Model Context Protocol, a standard for giving agents tools. |
| **Skill** | A file of instructions an agent consults to do a kind of work better. |
| **Token** | The unit of text an AI processes; plans limit how many you use. |
