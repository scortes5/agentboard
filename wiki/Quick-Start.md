# Quick Start

Five minutes from install to your first parallel agents.

1. **Add a project.** Press `+` next to the tabs at the top and pick your code folder.
2. **Open an agent.** Press **Claude** in the bottom bar (⇧⌘1 / Ctrl+Shift+1). The first time in a folder, answer *Yes, I trust this folder*.
3. **Ask something.** *"Explain what this project does and which files matter most."* The dot pulses while it works and turns green when it waits for you.
4. **Queue work.** Open **Tasks** (⇧⌘T) and write one to-do per line:
   ```
   add validation to the payment form
   @codex write tests for the shopping cart
   fix broken links in the README !
   ```
   Turn on **Run queue**. AgentBoard opens one agent per task, several at once.
5. **Review.** When a task says *Needs your review*, use *Go to the agent card*. With **Worktree per task** on, *View changes* lets you **Merge** or **Discard**.
6. **Look at everything.** Press **Diagram** (⇧⌘D) for a per-project, per-group view of every agent.
